# Nix-config для билда форка Sign-Box (signbox-lx) из РФ (с задушенными шеками и прочими ограничениями) 

## Предыстория
В какой-то момент мне потребоваласть поддержка протокола xhhtp которой не было в ванильной Сигне.
При этом у меня есть потребность юзать сгину как экзит ноду в Talescale-Headscale меш-сети.
Поэтому я поковырялась и выбрала этот форк. Но в nixpkgs он не добавлен. Да некоторые пакеты из зависимостей на доступных мне без VPN кеш-серверах были недоступны. 
Поэтому пришлось прям цепочку дериваций писать, чтоб это сбилдить.

## Состояние
В данный момент тут нейро-говно дисцилированное фиг пойми в каком виде из личного никс-конфига.
В планах пройтись по нему глазами и почти наверняка отрефакторить эту хрень, дабы подготовить в иделае нормальную деривацию с опшинсами.
Совсем в идеале мб подкину это в официальный nixpkgs как доведу до ума
